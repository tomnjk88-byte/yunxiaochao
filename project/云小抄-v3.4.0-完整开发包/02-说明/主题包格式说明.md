# 主题包格式

一个主题包就是一段 JSON，描述「这套皮肤长什么样」。商店里点「导出」拿到的、
别人发给你的、自己手写的，都是同一种东西。

## 最小可用示例

```json
{
  "schema": "yunx.theme",
  "v": 1,
  "name": "暮色橙",
  "author": "你的名字",
  "version": "1.0.0",
  "note": "琥珀 · 硬边界 · 户外看得清",
  "tags": ["深色", "高对比"],
  "dots": ["#FFB020", "#FFD79A", "#0A0A0C"],
  "tuning": {
    "accentKey": "amber",
    "paletteStyle": "expressive",
    "cardAlpha": 1.0,
    "cardRadius": 0.8,
    "borderScale": 1.44
  }
}
```

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `name` | 建议 | 卡片上的名字 |
| `author` | 否 | 作者，默认「本机导入」 |
| `version` | 否 | 版本号，默认 1.0.0 |
| `note` | 否 | 一句话介绍 |
| `tags` | 否 | 标签，商店里能按它筛 |
| `dots` | 否 | 三颗预览色，卡面渐变就用它们 |
| `id` | 否 | 唯一标识；没有就按名字 + 时间生成 |
| `tuning` | **是** | 真正的外观参数，见下 |

`tuning` 里可以只写你要改的那几项，没写的走默认值。

| 参数 | 范围 | 作用 |
| --- | --- | --- |
| `accentKey` | auto / ice / teal / violet / rose / amber / jade | 强调色 |
| `paletteStyle` | tonal / vibrant / neutral / expressive / mono | 色彩气质 |
| `colorSpec` | 2025 / 2021 | 鲜一点 / 沉一点 |
| `customAccent` | ARGB 整数 | 自定义强调色，0 = 不用 |
| `cardAlpha` | 0.35 – 1.0 | 卡片透明度，越小越透 |
| `blurScale` | 0 – 1.6 | 背景模糊倍数 |
| `scrimBias` | -0.35 – 0.35 | 背景遮罩，负变暗、正变亮 |
| `fontScale` | 0.85 – 1.15 | 字号缩放 |
| `cardRadius` | 0.6 – 1.6 | 卡片圆角倍数 |
| `borderScale` | 0 – 1.6 | 描边强度 |
| `shadowScale` | 0 – 1.6 | 投影强度 |
| `dividerScale` | 0 – 1.6 | 分割线强度 |
| `iconShape` | rounded / circle / square | 设置行图标底板 |
| `hideSubtitle` | true / false | 只留标题，隐藏说明 |
| `bottomDensity` | compact / normal / relaxed | 底栏行高 |
| `showSliderValue` | true / false | 滑杆右侧显示数值 |
| `progressiveScrim` | true / false | 背景上下边缘渐隐 |

## 打包成 zip（可带封面）

```
我的主题.zip
├── theme.json       ← 上面那段 JSON
└── cover.png        ← 可选，卡片封面（jpg / webp 也认）
```

安装：主题商店 → 右下角「从文件安装」→ 选 zip。

## 附：SukiSU / KernelSU 的 `.sukisu` 主题包

除了上面这种 json 包，v3.4.0 起也能直接吃 SukiSU 管理器那套主题包。
文件名通常长这样：`SukiSU-theme-遐蝶.sukisu`，外面可能还套了一层 zip。

### 它里面是什么

```
xxx.sukisu
├── 前 4 字节     "SKTH"
├── 12 字节        AES-GCM 的 IV
└── 剩下的         AES-GCM 密文（含 16 字节 tag）
        └─ 解开是一个 zip：
             theme.json                  管理器自己的外观配置
             background                  背景图（webp / jpg / png）
             card_background             卡片底图
             bottom_bar_icon_home        底栏图标 ×4
             bottom_bar_icon_superuser
             bottom_bar_icon_module
             bottom_bar_icon_setting
```

密钥是管理器源码里的常量，所以任何拿到源码的人都能解开 —— 这个格式防的是手改，
不是防拆。云小抄只是照同样的规则读，不做二次分发。

### 云小抄怎么用它

| 包里的东西 | 落到云小抄哪里 |
| --- | --- |
| `background` | 整屏背景（主题设置里那张自定义背景，同一个位置） |
| `card_background` | 卡片底图，卡组模式和普通卡片都铺 |
| `bottom_bar_icon_*` | 底部 Dock 的四格图标（小抄 / 连招 / 主题 / 我的） |
| `keyColor` 或背景主色 | 强调色（按钮、选中态、进度条） |
| `cardBackgroundAlphaPercent` | 卡片不透明度 |
| `customBackgroundBlurPercent` | 背景模糊倍数 |
| `customBackgroundScrimPercent` | 背景压暗程度 + 上下渐隐 |
| `colorStyle` / `colorSpec` | 调色板气质 / 色彩规范 |
| `customTexts` | 只存下来在详情里展示，不往界面硬塞 |

**不映射的部分**：模块排序、KPM、Zygisk 开关、页面标题那一堆是管理器自己的业务，
云小抄没有对应物。硬套只会得到一堆看不懂的开关，所以跳过。

### 导入

主题商店 → 右下角「从文件安装」→ 选 `.sukisu`，或者套着 .sukisu 的那个 zip。
导入后会自动应用，并在商店最上面那张大卡里显示，左上角标 `SUKISU`。

同一个包重复导入会覆盖旧的（按包名认），不会堆出一串同名卡片。

### 已知限制

- 主题包**不带云小抄的字体和排版**，`fontScale` / `bottomDensity` 这类走默认值。
- 包里的文案（「阁下的内核版本喵~」）没有对应位置，不会改界面文字。
- 「复制主题文本」出去的是纯参数版，不含图片 —— 图片是本机私有目录里的文件，
  路径在别人手机上无效。要完整搬走，请直接发 `.sukisu` 原包。

---

## 兼容

- 只有 `tuning` 没有外壳的老格式（v2.12 之后「导出当前主题」复制出来的那段）也能直接导入，
  会自动命名成「导入的主题」。
- 主题包**不带壁纸**。背景图是本机文件，换机或被删就没了；主题只负责颜色、圆角、
  透明度这些「画出来的东西」。
- SukiSU 的 `.sukisu` 包**带图**。这些图会被搬进 App 私有目录，删包时一并删掉；
  想完整搬去另一台手机，请发原包，不要发「复制主题文本」那段。
