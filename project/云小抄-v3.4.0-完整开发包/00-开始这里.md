# 云小抄 v3.4.0 · 先看这里

## 装哪个

`01-安装包/云小抄-v3.4.0-release.apk` —— 直接装，覆盖旧版即可（同一套签名）。

## 这一版多了什么

**SukiSU 的主题包能直接导进来了。** 就是你发的那种 `SukiSU-theme-遐蝶.sukisu`，
外面再套一层 zip 也认。

导入路径：我的 → 主题商店 → 右下角「从文件安装」→ 选中包。

选完会当场应用：

| 包里的 | 变成 |
| --- | --- |
| `background` | 整屏背景 |
| `card_background` | 卡片的底图（卡组和普通卡片都铺） |
| `bottom_bar_icon_*` | 底部 Dock 的四格图标 |
| 背景主色 / `keyColor` | 强调色（按钮、选中态） |
| 卡片透明度 / 模糊 / 遮罩 | 卡片的透、糊、暗 |

**要先切到 Dock 才看得见四个图标**：我的 → 主题设置 → 底栏导航 → 底部 Dock。
抽屉模式下卡片和背景照样换，只是没有底栏。

## 另外两件事

1. **下载量删了。** 主题商店的卡片上不再有「⇩ 1.8k」这种东西，内置包只留一颗心，
   导入的包干脆不显示数字。排序里的「最热」也改成按点赞。
2. **重复导入会覆盖。** 同一个包名反复导，只会留最新那份，不会堆出一串「遐蝶」。

## 先看样图

`02-说明/云小抄-应用SukiSU主题-遐蝶-样图.html` 用浏览器打开 ——
那是这套包应用之后的实际样子：背景、卡面、Dock 四个图标、取出来的紫色强调色。

## 已知限制

- 包里的文案（「阁下的内核版本喵~」）不会替换云小抄的界面文字。
  那些字段是 SukiSU 管理器自己的页面标题，云小抄没有对应位置，硬套会变成四不像。
- 模块排序、KPM、Zygisk 开关这些也不搬 —— 跟外观无关。
- 底栏图标只在 Dock 导航下显示。
- 主题包的图存在 App 私有目录；卸载 App 会一起没，重装要重新导入原包。
